# v0.3.0 — Install Target (Default / Custom Device) + Cron Fix + PATH Hint

## Goal

Three improvements bundled into one release:

1. **Bug fix**: `cron_daily_time` was installed backwards (hour/minute swapped) — the wizard accepted `07:30` but produced a crontab line `07 30 * * *` which cron rejects as "bad hour" (hour 30 is invalid; cron wants minute first, then hour, so `30 7 * * *`).
2. **UX hint**: After install, the `research-pipeline` binary is in `.venv/bin/` which is not on `$PATH` by default. The install summary now shows the correct invocation and the README explains how to activate the venv for the user's shell (bash, zsh, fish).
3. **Feature**: Install Target option in the wizard. After picking LLM/Telegram/features, the user picks where to install: **This device** (local, current behavior) or **Custom device** (a remote server reached via SSH). The remote flow generates a Bash setup script, pushes it via SSH, and streams remote output live.

## Decisions

- **Cron fix**: Swap the unpack so `hour, minute = parts`, then `cron_line = f"{minute} {hour} * * * …"` produces the correct `30 7 * * *` for input `07:30`.
- **PATH hint**: Don't try to mutate the user's shell rc. Just print the right commands in the wizard's final summary and document them in `INSTALL.md` per shell.
- **SSH auth**: Password only (user-supplied at runtime, never stored). No SSH-key path in v0.3.0.
- **No sudo**: The SSH-User is expected to have everything ready (root login, or a user with NOPASSWD sudo + Ollama pre-installed, or a pre-provisioned environment). The tool doesn't try to escalate.
- **Setup-script approach** (not remote-Wizard): The wizard collects everything locally, writes `.env` locally (for the validation test-call), then generates one Bash setup-script that does all remote work in one SSH call. Output streams live to the local terminal.

## Bug fix #1 — `src/research_pipeline/install/cron.py`

Current (broken):
```python
time_parts = CFG.cron_daily_time.split(":")
...
minute, hour = time_parts  # "07:30" → minute="07", hour="30" — WRONG
cron_line = f"{minute} {hour} * * * cd {install_dir} && …"  # → "07 30 * * *" invalid
```

Fixed:
```python
parts = CFG.cron_daily_time.split(":")
if len(parts) != 2:
    return False, f"Invalid schedule time: {CFG.cron_daily_time!r}"
hour, minute = parts  # HH:MM
# Cron syntax is: MIN HOUR DOM MON DOW
cron_line = f"{minute} {hour} * * * cd {install_dir} && …"
```

Also update `get_cron_entry()` regex so it picks up the corrected order:
```python
match = re.match(r"^(\S+)\s+(\S+)\s+.*research[_-]pipeline", line)
if match:
    minute, hour = match.groups()  # cron's MIN HOUR order
    schedule = f"{minute} {hour} * * *"
```

### Code changes

**New file `src/research_pipeline/install/remote.py`:**

```python
"""SSH-based remote installation helpers."""
from __future__ import annotations
import shutil
import subprocess
from dataclasses import dataclass
from pathlib import Path


class RemoteInstallError(RuntimeError):
    """Raised when a remote operation fails."""


@dataclass
class SSHConnection:
    host: str
    user: str
    password: str
    port: int = 22

    def _sshpass_args(self, *cmd: str, input: bytes | None = None, check: bool = True) -> list[str]:
        return [
            "sshpass", "-p", self.password,
            "ssh",
            "-o", "StrictHostKeyChecking=accept-new",
            "-o", "UserKnownHostsFile=" + str(Path.home() / ".ssh" / "known_hosts_research_pipeline"),
            "-p", str(self.port),
            f"{self.user}@{self.host}",
            *cmd,
        ]

    def check_local_requirements(self) -> None:
        """Verify sshpass is installed locally. Raises if not."""
        if not shutil.which("sshpass"):
            raise RemoteInstallError(
                "sshpass is not installed locally. Install with:\n"
                "  Debian/Ubuntu: sudo apt install sshpass\n"
                "  macOS: brew install hudochenkov/sshpass/sshpass\n"
                "  Fedora: sudo dnf install sshpass"
            )

    def check_connection(self) -> tuple[bool, str]:
        """Verify SSH connection works. Returns (ok, ssh_banner)."""
        result = subprocess.run(
            self._sshpass_args("echo", "ok"),
            capture_output=True, text=True, timeout=15, check=False,
        )
        if result.returncode != 0:
            return False, result.stderr.strip()
        return True, "ok"

    def check_python(self) -> str | None:
        """Return remote python3.11+ version string, or None if missing."""
        result = subprocess.run(
            self._sshpass_args("command -v python3.11 || command -v python3 || echo none"),
            capture_output=True, text=True, timeout=15, check=False,
        )
        if result.returncode != 0 or "none" in result.stdout:
            return None
        version_result = subprocess.run(
            self._sshpass_args(result.stdout.strip(), "--version"),
            capture_output=True, text=True, timeout=15, check=False,
        )
        return version_result.stdout.strip() if version_result.returncode == 0 else None

    def stream_command(self, command: str, *, timeout: int = 1800) -> int:
        """Run a command on the remote host, streaming stdout/stderr live to the local terminal.

        Returns the remote exit code. Raises RemoteInstallError on connection failure.
        """
        import sys
        proc = subprocess.Popen(
            self._sshpass_args(command),
            stdout=subprocess.PIPE,
            stderr=subprocess.STDOUT,  # merge so the user sees a single chronological stream
            bufsize=1,
            text=True,
        )
        assert proc.stdout is not None
        try:
            for line in proc.stdout:
                print(f"  [remote] {line}", end="")
                sys.stdout.flush()
            proc.wait(timeout=timeout)
        except subprocess.TimeoutExpired:
            proc.kill()
            raise RemoteInstallError(f"Remote command timed out after {timeout}s")
        except KeyboardInterrupt:
            proc.kill()
            raise RemoteInstallError("Aborted by user (Ctrl+C)")
        return proc.returncode

    def upload_file(self, local_path: Path, remote_path: str) -> None:
        """Upload a file via scp+sshpass."""
        result = subprocess.run(
            [
                "sshpass", "-p", self.password,
                "scp",
                "-o", "StrictHostKeyChecking=accept-new",
                "-o", "UserKnownHostsFile=" + str(Path.home() / ".ssh" / "known_hosts_research_pipeline"),
                "-P", str(self.port),
                str(local_path),
                f"{self.user}@{self.host}:{remote_path}",
            ],
            capture_output=True, text=True, timeout=60, check=False,
        )
        if result.returncode != 0:
            raise RemoteInstallError(f"SCP upload failed: {result.stderr.strip()}")
```

**`src/research_pipeline/install/wizard.py` changes:**

1. New step `[1/9] Install Target` at the top. Default = 1 (this device).
2. If target == 2 (custom device), collect SSH credentials and validate:
   - `sshpass` installed locally
   - SSH connection works (banner returned)
   - Remote has `python3.11` (or `python3` ≥ 3.10 if 3.11 unavailable)
3. After all the existing config steps + `.env` write, branch on target:
   - **This device**: call existing `cron.install_cron_entry()` (now with the bug fix).
   - **Custom device**: write a setup script to a temp file, show the user a summary, `scp` it to `~/research-pipeline-setup.sh` on the remote, then `stream_command("bash ~/research-pipeline-setup.sh")`. Print the final summary adapted for the remote host.
4. Add a `RemoteInstallError` catch path that explains cleanly and exits non-zero.

**New file `src/research_pipeline/install/setup_script.sh.tmpl`** (rendered as a string template):

```bash
#!/usr/bin/env bash
# Auto-generated by research-pipeline-install. Do not edit by hand.
set -euo pipefail

REMOTE_DIR="$HOME/research-pipeline"
LOG_DIR="$REMOTE_DIR/logs"

# 1. Install Ollama if missing
if ! command -v ollama >/dev/null 2>&1; then
  echo "Installing Ollama..."
  curl -fsSL https://ollama.com/install.sh | sh
fi
echo "Ollama $(ollama --version)"

# 2. Pull model (idempotent)
echo "Pulling model ${LLM_MODEL}..."
ollama pull "${LLM_MODEL}"

# 3. Clone repo
if [ ! -d "$REMOTE_DIR/.git" ]; then
  git clone https://github.com/DavidVossebuerger/Research-Pipeline.git "$REMOTE_DIR"
fi
cd "$REMOTE_DIR"

# 4. venv + deps
if [ ! -d .venv ]; then
  python3.11 -m venv .venv
fi
.venv/bin/pip install -U pip >/dev/null
.venv/bin/pip install -e ".[dev]"

# 5. Write .env (overwrites any local one)
cat > .env <<'ENVEOF'
${ENV_CONTENTS}
ENVEOF

# 6. Install cron entry (user-crontab, no sudo)
CRON_LINE="${CRON_MINUTE} ${CRON_HOUR} * * * cd $REMOTE_DIR && .venv/bin/python -m research_pipeline.cli run >> $LOG_DIR/pipeline.log 2>&1"
mkdir -p "$LOG_DIR"
( crontab -l 2>/dev/null | grep -v 'research_pipeline' ; echo "$CRON_LINE" ) | crontab -

echo "✓ Install complete. Try: cd $REMOTE_DIR && .venv/bin/research-pipeline run --dry-run"
```

The wizard fills `LLM_MODEL`, `ENV_CONTENTS` (the full .env text), `CRON_MINUTE`, `CRON_HOUR` from the collected config before writing the file to a `tempfile.NamedTemporaryFile`.

## Out of scope

- SSH-key authentication (only password in v0.3.0)
- Sudo / privilege escalation inside the tool
- Idempotent re-runs (the script does a fresh clone)
- Multi-hop SSH / Bastion host
- Remote-update (`research-pipeline-install update --remote` — separate future release)
